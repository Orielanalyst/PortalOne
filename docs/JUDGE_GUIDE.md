## Review the work boundary

1. Read [PROVENANCE.md](PROVENANCE.md) for the reference prototype, declaration
   boundary and Wildcard explanation. The 24 October checkpoint is not backdated.
2. Inspect the baseline commit `42fb95c1569b5dbeb01abb16dca5cff2a771debb`, its
   file/blob manifest and the subsequent commit diff. Existing published history,
   tag `v0.1-tracking` and the UI stash are preserved.
3. Follow [BUILD_LOG.md](BUILD_LOG.md) for dated results and limits,
   [AI_USAGE.md](AI_USAGE.md) for assistance disclosure, and
   [COMMIT_POLICY.md](COMMIT_POLICY.md) for our internal review practices.
4. Reproduce the bounded connection checks in [ENVIRONMENT.md](ENVIRONMENT.md).
   Then run `bun run demo:relief-agent` or the configured `--live` path. The
   initial overweight draft is a labelled stress-test input. The preserved
   [earlier live trace](evidence/relief-agent-live-early-2026-10-24.json) also shows
   a slower eligible option rejected by the objective check, and repeated invalid
   deadline proposals overridden by the hold limit. These are recorded outcomes,
   not a transcript with a prewritten successful model answer.
5. Inspect the live trace's source hashes and `sourceCommit`. It records separate
   planner/validator queries, constraint calculations, model IDs, timing and usage.
   The earlier receipt preserves `73cfba5`; the latest trace records its checkout
   and executed entry artifact after hardening. No dispatch was authorized.

## Evidence required as features land

Every completed gate must link to its commit, input/data revision, execution
mode, test or run receipt, and limitations. Runtime receipts must connect
observations, query results, state versions, rejected constraints, revisions,
actual model identity and the operator's final action. A local pass must be
distinguished from remote CI; fixture results must be distinguished from live
sponsor calls. Credentials and private reasoning are excluded.

The repository was made public on 25 October at the user's request; anonymous
GitHub access was verified. The current implementation is on
[`codex/execution-readiness`](https://github.com/Orielanalyst/PortalOne/tree/codex/execution-readiness).
The default branch is still `main`; release integration, a clean judge setup and
final submission materials remain work. Repository visibility does not make the
local credential-bearing operator server publicly hosted.
