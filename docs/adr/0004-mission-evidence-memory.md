# 0004 — Evidence changes invalidate published mission snapshots

Date: 2026-10-25. Status: implemented; live rehearsal evidence is recorded separately.

Reuse the retained Meterless World Model engine for the browser workflow. Store
compact normalized facts as immutable evidence entities, bind every published
plan to its evidence entity, and keep the engine's actual events and audit entries.
Raw Kobo text, reporter identities, credentials and reporter coordinates do not
enter this memory. Existing SQLite assessment checks remain an independent guard.

A new project evidence revision invalidates earlier dependencies. Record changed
values and retain invalidation even if the source later returns to an older
revision. This is conservative project-level invalidation; it does not claim
incident-to-road dependency resolution. Forwarded records remain unverified.

The watch commissions the same committee graph for the replacement, links both
runs, and publishes a cross-mission diff. Source reads before export and before
download publication catch evidence drift during model generation or rendering.
The exporter must invoke the final source check before it can publish a ready pack.
At most twelve federation query slots and ten minutes bound each committee run.

Keep previous PDF/GIS bytes immutable. Mark the old plan and report superseded;
default old download URLs return 409. Explicit historical links retain access,
carry a superseded filename/header, and preserve the original checksum. Reading
a plan or report pins that run until the operator chooses its replacement.

One live rehearsal exposed repeated unknown citation IDs in the fast model's
publication repair. Keep that failure. Use short source handles in model output
and resolve them against the supplied catalogue during the real provider stream.
Hold incomplete handles; support bounded groups/ranges; reject unresolved sources.
Keep the mapping in each published document receipt. Use Ultra for bounded repairs:
at most one per document and two across the run. Remove rejected citation markers
and unsupported dates from repair input, requiring support to be selected again.
Reject unsupported ISO calendar dates rather
than filling a missing operator deadline. ISO timestamps supply supported calendar
days too. A pure "None" under required changes is an evaluation control; explanatory
claims still require citations. Independent evaluation still follows.

Persistent memory and completed documents survive restart. The polling watch and
an interrupted graph do not automatically resume. This work grants no field
verification or dispatch approval.
